# Fonts

The same faces the game loads from Google Fonts, as files, for making more
captions or cards.

- `Silkscreen-Regular.ttf`, `Silkscreen-Bold.ttf` — Jason Kottke. SIL Open Font
  Licence 1.1 (`OFL-Silkscreen.txt`). Silkscreen is a pixel face: set it at a
  multiple of 8px and turn anti-aliasing off, or it goes soft. It has **no ₹
  sign** — set money in IBM Plex Mono, as the game does.
- `IBMPlexMono-Regular.ttf` — IBM. SIL Open Font Licence 1.1.
