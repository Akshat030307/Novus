If they ask

Is the AI picking the exercise? No. A rule picks it; TinyFish fetches current reading for the teacher. Deliberate — "the model said so" is not a reason to drill a student.

What's real? The Casebook cases and the teacher's reading list. Every tradable company, price and loan file is invented, on purpose: real tickers turn a learning game into advice.

Privacy? A teacher sees attempts and a shared summary. Never a save, cash, or a transcript. Enforced in Postgres, not in the screen — 24 checks in tools/sql, all passing.

Built with? React, Phaser, Supabase, TypeScript. Rules, world and interface kept in separate layers so the market stays testable.
