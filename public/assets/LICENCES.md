# Asset licences

Every sprite, tile, font and sound in this folder gets a line here, with its
source and licence, on the day it is added. Backfilling this later is
miserable, and a game with unclear asset licensing cannot be shown publicly.

## Picking sprite packs

Kenney's packs are the easiest starting point: public domain, consistent, and
they include top-down tiles and characters. OpenGameArt has far more variety
but the licence differs per file, so check each one.

Pick one pack and stay in it. Mixing packs is the fastest way to make a game
look amateur, because pixel size and palette rarely match between artists.
